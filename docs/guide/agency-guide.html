1. What the AI SEO Lead is

An AI employee that runs the full organic-growth function for every client website, the way an experienced Senior SEO Manager would. It is not a blog generator or a rank tracker. It monitors, diagnoses, prioritises, prepares the work, executes only what you approve, verifies the result and reports on business outcomes.

It does on its ownCrawls and audits, Search Console / GA4 / Business Profile reading, keyword research, briefs and drafts, competitor and backlink reviews, AI-visibility checks, daily/weekly/monthly reports, the dashboard.
It asks firstAny change to a live site or profile: titles, meta, content, schema, canonicals, redirects, robots.txt, sitemaps, publishing, GBP posts, Search Console actions, outreach.
It never doesHandle passwords; open email, hosting, users, plugins or settings; delete pages or disavow links on its own; send anything to clients; spend money; buy links.

A manager with eight specialists

The main session is the AI SEO Manager (orchestrator). For broad work it briefs eight specialist agents, then merges their findings into one prioritised plan:

SpecialistCovers
Keyword ResearchOpportunities, intent, clusters, keyword-to-page mapping, gaps
Technical SEOCrawling, indexing, canonicals, redirects, robots, sitemaps, internal links, schema, speed
Content SEOBriefs, content audits, refresh/merge decisions, CTR fixes
Off-page SEOBacklinks, referring domains, digital PR and outreach ideas
AnalyticsSearch Console + GA4 evidence, anomalies, conversions, KPIs
AI SearchMentions and citations in AI Overviews, ChatGPT, Perplexity, Gemini, Copilot
Local SEOGoogle Business Profile, reviews, NAP, location pages
Competitor IntelligenceCompetitor new/updated pages, SERP changes, keyword gaps

Section 2

Before you start: checklist

Gather these before the setup session. Allow about 30–45 minutes for the first client and 10 minutes for each additional one.

Software
  • Claude desktop app (Mac or Windows) with Cowork on a paid plan
  • Claude in Chrome extension installed in Google Chrome
  • The two files: elevatedigi-seo-lead.zip (plugin) and ElevateDigi-SEO-Workspace.zip (client memory)
Accounts (agency Google account)
  • Google Search Console access to each client property
  • Google Analytics 4 access (Viewer is enough)
  • Google Business Profile access for local clients
  • Bing Webmaster Tools
Per client website
  • A WordPress user with the Editor role for the SEO Lead to work in (or the platform admin, e.g. Graphy)
  • Name of the person who approves changes
  • Developer and writer contacts
Business information per client
  • Goals: leads / bookings / sales, and what counts as a qualified lead
  • Revenue goal or target leads per month
  • 3–5 competitors the client actually loses business to
  • Things the brand must never claim

Do this first: rotate shared passwords

If passwords were kept in a spreadsheet or known by a departing employee, change them now (WordPress admins, hosting, email), turn on two-factor authentication, remove unknown WordPress users, and move credentials into a password manager. The SEO Lead never needs those passwords.
Section 3

Setup in 8 steps

1

Install the plugin in Cowork

Open the Claude desktop app → switch to Cowork → Customize → Plugins → Upload → choose elevatedigi-seo-lead.zip → confirm. Uploading inside a normal chat or a Project does not install a plugin. When a newer version arrives, upload it the same way; it replaces the old one.
2

Connect Chrome

Install the Claude in Chrome extension and, in Cowork, set Chrome as the preferred browser. This is how the SEO Lead reads your Google tools and edits WordPress, using your sessions and never your passwords.
3

Create a dedicated Chrome profile: "SEO Lead"

In Chrome: profile icon → Add → name it SEO Lead. In this profile only, sign in to:
  • the agency Google account (Search Console, GA4, Business Profile)
  • Bing Webmaster Tools
  • each client's /wp-admin with the Editor user (Graphy admin for Abhyaass)
Do not sign in to email, hosting/cPanel or domain registrars in this profile.
4

Set up the workspace folder

Unzip ElevateDigi-SEO-Workspace.zip into Documents/ElevateDigi SEO. Avoid any folder that Google Drive or OneDrive syncs. In Cowork, grant access to that folder. It holds every client's memory: profile, task queue, audit log, crawls, reports.
5

Point Chrome downloads to the inbox

In the SEO Lead Chrome profile: Settings → Downloads → Location = Documents/ElevateDigi SEO/_inbox, and turn off "Ask where to save each file". Search Console and GA4 exports then land where the SEO Lead can read them.
6

Run /seo-setup

In Cowork, type /seo-setup. It finds the workspace and opens each tool in Chrome (read-only) to check what's connected. It also tests whether its scripts can reach client websites. You get a health table (✅ / ⚠️ / ❌) with one plain fix per line. Re-run /seo-doctor any time.
7

Create the scheduled tasks

Accept the offer at the end of setup, or create them in Cowork's scheduled tasks:
WhenPromptYou receive
Mon–Sat, 9:10 AM/dailyDaily health summary
Monday, 8:45 AM/weeklyWeekly review per client + approvals needed
3rd of each month, 10:20 AM/report <client> then /dashboardMonthly report drafts
Your computer must be on and the Claude app open at those times. The cloud copy still runs the Monday check if it isn't.
8

Complete onboarding for each client

Open clients/<client>/profile.md and onboarding.md, or just answer the SEO Lead's questions. Fill in the TBD items: revenue goals, approver, developer/writer, confirmed competitors. Once Search Console and GA4 are connected, ask "record the KPI baseline for <client>". When the onboarding checklist is complete, the gate changes to PASSED. Until then, strategic advice is labelled provisional.
Section 4

Security & access rules

Least privilege, your own sessions, a full audit trail. These rules are built into the SEO Lead; the agency's part is to set up access the same way.

SystemAccess to giveHow
WordPressEditor role, not AdministratorCreate a user, sign in to it in the SEO Lead Chrome profile
Search ConsoleRestricted or Full userGSC → Settings → Users and permissions
GA4ViewerAdmin → Property access management
Business ProfileManager, only if it will postBusiness Profile → People and access
Hosting, cPanel, email, domains, billingNoneHumans only, never in the SEO Lead profile

What the SEO Lead will never do

  • Type, save or reveal a password; if it meets a login page it stops and asks you
  • Open Users, Plugins, Themes, Settings or Tools pages in WordPress
  • Send anything to a client or contact third parties
  • Mix one client's data, voice or keywords with another's

What it always does

  • Backs up the old value before any change and writes rollback steps
  • Logs every action with source data, approval, actor and verification
  • Escalates security incidents (spam pages, injected links, unknown admins) the same day
  • Labels findings Observed or Hypothesis, with source, dates and confidence
Section 5

The operating rhythm

Observe→Diagnose→Decide→Execute→Verify→Learn

Daily: health summary (5 minutes to read)

Checks Search Console and GA4, money pages, robots.txt, sitemaps, spam URLs, priority keywords, competitor signals and overdue tasks. Before reporting anything it asks: is it meaningful after normal volatility and data delay? What explains it? Are conversions affected? Could tracking or a release explain it? Does it need escalation?

ClientWhat changedWhy it mattersEvidenceActionOwnerUrgencyStatus
ExampleCalangute page title changedMoney page; CTR riskDaily watch, 24 NovConfirm with devAIP2Pending

Quiet day: "No meaningful change" plus what was checked. It never invents findings.

Weekly: review per client (Monday)

Seven deliverables: performance & anomaly report · keyword opportunities (positions 5–20, weak CTR) · content production/refresh plan · technical issue tracker · competitor summary · backlink & local observations · next week's 3–5 priorities. It also answers in writing the seven questions a senior SEO manager asks, including "why did traffic change?" and "which action has the greatest business impact next?".

Monthly: report & roadmap (by the 5th)

Business-outcome report (month on month and year on year) · comprehensive audit · competitor & keyword-gap report · keyword map & content calendar · backlink report · AI-visibility observations · next-month roadmap. Every report is a draft for founder review; the agency sends it to the client.

On event: traffic drop

/diagnose validates the drop and segments it, finds the pages and queries responsible, and checks technical and release changes and SERP shifts. You get ranked hypotheses with confidence and what would prove each one, then fixes that need your approval, followed by monitoring at 14 and 28 days.

Reply in plain words: "approve all", "approve 1 and 3", "change row 2 to …" or "reject 2". Nothing changes on a live site until you do. The task tool technically refuses to move a task to execution while approval is still pending.

Task workflow

Detect→Investigate→Recommend→Await approval→Execute→Verify→Report→Close

Before any task is closed (10-point gate)

Aligned with a business objective · supported by current evidence · intent and user impact considered · impact, confidence, effort and risk assessed · approval needed? · approval recorded · executed within scope · verified live · action, data, time and outcome logged · follow-up measurement date set.
Section 8

Task queue & dashboard

One prioritised queue per client

Every finding becomes a task with: priority, score, owner, approval, status (Pending / In Progress / Completed / Blocked), workflow stage, verification and due dates. Score = Impact × Confidence ÷ Effort (each 1–5). It ranks tasks against each other and is not a traffic forecast. Risk and urgency override the score.

PriorityExampleExpected response
P0 CriticalSite down, accidental de-indexing, tracking failure, hack/spamEscalate immediately
P1 HighImportant pages hit by indexing, canonical, redirect or visibility issuesUrgent remediation
P2 MediumContent gaps, internal links, CTR opportunitiesThis work cycle
P3 LowMinor metadata, low-impact tweaksBacklog, batch

SEO Intelligence Dashboard

Open Documents/ElevateDigi SEO/_dashboard.html in any browser, or type /dashboard. One page for the whole portfolio:

  • Portfolio row per client: status, daily-watch alerts, open P0/P1, approvals waiting, last crawl, Search Console summary, onboarding gate, last daily/weekly/monthly run
  • Client cards: top 5 actions, alerts, site health vs previous crawl, integration status and data freshness, recent activity, completed and verified tasks

Founder routine (10 minutes a day)

Read the daily summary → open the dashboard → answer pending approvals with /tasks approvals → forward Tier C items to the developer or writer.

Getting the best output

Give it first-hand input: real prices, specs, photos, case results, customers' top 20 questions. Without them, content stays generic, doesn't rank and doesn't get cited. Ask "what do you need from the client?" at any time.

Allow access

Section 12

Troubleshooting

ProblemFix
"Workspace not found"The folder moved or access was removed. Grant Cowork access again and run /seo-setup
It stops at a Google or WordPress login pageExpected: it never types passwords. Sign in yourself in the SEO Lead Chrome profile, then say "continue"
It's using the wrong Chrome or accountSet Cowork's preferred browser to the SEO Lead profile's Chrome; check the profile shows the agency account
Search Console export not foundChrome's download folder isn't _inbox. Fix step 5 and export again
Crawl fails with a network errorCowork's sandbox can't reach the site. Allow network access for client domains in Cowork settings; meanwhile it uses Chrome for spot checks and says so
Site blocks the crawler (403/406)The host's firewall (e.g. mod_security). Ask the host to allow the crawler, or rely on Search Console data
PageSpeed check fails (quota)Create a free PageSpeed Insights API key in Google Cloud Console and save it when asked
Scheduled task didn't runThe computer was off or the Claude app was closed. Run the command manually; the cloud Monday check still ran
Reports say "not available"A data source isn't connected (see the dashboard's integration status). It labels missing data instead of guessing
Two computers in the agencyInstall the plugin on both, but keep one workspace as master (sync via the GitHub repo) to avoid conflicting task queues

Updates and backups

  • Plugin updates: upload the new elevatedigi-seo-lead.zip in Cowork → Customize → Plugins; client memory is untouched.
  • Backups: the workspace folder is the employee's memory. Back it up weekly, or keep it in sync with the GitHub repository AIED2026/Ai-SEO-Employee.
  • Specifications: the founders' Playbook and Master Operating Checklist live in the repo's docs/ folder, with a coverage map and an acceptance checklist showing current status.

Final operating principle

Judge the AI SEO Lead by the quality of its decisions, the safety and accuracy of its execution, and its measurable contribution to clients' organic business outcomes. Do not judge it by how many keywords, pages or reports it produces.
